# 뚝딱 코딩 로봇

초등학생을 위한 블록 코딩 퍼즐 웹 앱입니다. 명령 블록을 쌓아 로봇이 보석을 모으게 하면서 순차 실행, 반복, 조건, 함수, 변수, 알고리즘을 차례대로 배웁니다.

**바로 하기: https://zent1216.github.io/ddukttak-coding-robot/**

6개 등급을 마친 뒤에는 자유 모드에서 마음대로 만들 수 있습니다.

설치할 것이 없습니다. 위 주소를 열거나 `index.html` 파일 하나를 크롬, 엣지, 사파리 같은 브라우저에서 열면 바로 할 수 있고, PC·태블릿·휴대폰에서 모두 동작합니다.

## 등급과 단계

6개 등급, 등급마다 8단계씩 모두 48단계입니다. 앞 등급에서 6단계 이상 성공하면 다음 등급이 열립니다. 첫 화면의 "모든 등급 열기 (선생님용)"를 켜면 처음부터 모든 등급을 고를 수 있습니다.

| 등급 | 주제 | 배우는 개념 |
|---|---|---|
| 초급 | 명령 순서 익히기 | 순차 실행, 방향 바꾸기 |
| 초중급 | 반복으로 짧게 | 반복, 패턴 찾기 |
| 중급 | 반복 속 반복, 버그 잡기 | 중첩 반복, 조건 반복, 디버깅 |
| 중고급 | 조건으로 판단하기 | 만약/아니면, 센서, 보석 줍기, 여러 지도에서 통하는 프로그램 |
| 고급 | 함수와 변수 | 나만의 블록(함수), 변수 n |
| 심화 | 알고리즘으로 생각하기 | 오른손 미로 알고리즘, 일반화, 최소 블록 최적화 |

## 자유 모드

첫 화면의 "자유 모드" 카드로 들어갑니다. 정해진 문제 없이 오브젝트를 추가하고 블록을 끌어다 놓아 게임, 그림, 이야기를 만듭니다.

- 블록 분류: 시작, 흐름, 움직임, 생김새, 붓, 소리, 판단, 계산, 자료, 로봇
- 오브젝트: 그림 이모지, 글상자, 내 그림 올리기, 로봇 만들기
- 로봇 만들기: 몸체, 색, 바퀴, 거리 센서, 라인 센서를 골라 조립하고 바퀴 속도와 센서 값으로 제어합니다. 로봇은 화면 안의 가상 로봇입니다.
- 작품은 사용자별로 자동 저장되고, 파일로 저장하고 불러올 수 있습니다.

## 수업에 쓸 때 도움이 되는 기능

- 단계마다 개념 설명과 힌트가 있습니다.
- 실행 중인 블록이 노란 테두리로, 벽에 부딪힌 블록이 빨간 테두리로 표시되어 어디서 틀렸는지 찾기 쉽습니다.
- 각 등급에 이미 들어 있는 틀린 프로그램을 고치는 디버깅 단계가 있습니다.
- "글자 코드로 보면" 칸에 블록 프로그램이 파이썬 모양 코드로 바뀌어 보여서 텍스트 코딩으로 넘어가는 다리가 됩니다.
- 블록을 적게 쓸수록 별을 더 받습니다(최대 3개). 별과 진행 상황은 그 브라우저에 사용자별로 저장됩니다.
- 첫 화면에서 사용자를 추가하고 이름을 정할 수 있고, 사용자별로 기록을 초기화할 수 있습니다.
- 기록이 지워졌을 때는 "단계로 바로 가기"로 원하는 단계로 이동합니다. 앞 단계는 성공(별 1개)으로 표시됩니다.

## 단계 검사

모든 단계가 의도한 방법으로 풀리는지, 블록 개수 제한 안에서 풀리는지, 디버깅 단계의 틀린 프로그램이 실제로 실패하는지 확인하는 스크립트입니다. Node.js가 필요합니다.

```bash
node tests/verify-levels.js
```
